# Runtime executables

Place your verified SteamOS-compatible x86_64 builds here:

- `aria2c`: https://github.com/aria2/aria2
- `7zz`: https://www.7-zip.org/download.html

Set executable permissions before packaging. Binaries are ignored by Git. Check each build's license, dependencies and corresponding source obligations before distributing an installation ZIP. See `docs/DEVELOPMENT.md` and `THIRD_PARTY_NOTICES.md` in the project root.
