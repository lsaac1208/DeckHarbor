# 代码来源记录

初始开发输入是用户提供的 `NewFreedeck.v.0.3.zip`，不是从已确认授权的上游 Git 仓库克隆。原始包 SHA-256：

```text
b33bc4c9170b1758c9ffbbced41650811f769934e0740885a41384d36b35756e
```

本仓库从整理后的源码建立首次 Git 提交，不包含原作者的 Git 历史。原始包没有项目总许可证，见 [许可状态](../LICENSE.md)。平台图标、基础 Python / Rust 代码及相关配置来源于该输入；后续界面、目录、游戏库与模拟器改进记录在各版本变更文档中。

仓库发布整理移除了硬编码服务凭据，并排除本机编译文件、游戏数据、账号状态、缓存、日志和旧安装包。源码包不是 Decky 运行安装包。
