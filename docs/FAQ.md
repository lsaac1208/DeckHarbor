# 常见问题

### 与 NewFreedeck 是什么关系？

基于用户提供的 NewFreedeck v0.3 代码二次开发，不代表原项目官方。数据目录和部分内部标识继续沿用，Decky 名称和安装目录已经更名。

### 来源刷新慢或报错？

本地内容先显示，远端后台更新。旧目录上游可能超时，可在“来源”页查看状态和独立刷新。默认缓存 30 分钟，自动失败重试间隔至少 60 秒。

### Switch 为什么没有商业游戏？

别名修复只能恢复已有目录的条目。全新安装不附送商业 ROM 目录；新增 20 项是 4TU 自制游戏，不能当作已验证可在模拟器运行的商业游戏包。

### Steam / Flathub 为什么没有一键下载？

这些条目通过上游商店或项目页获取，不调用旧网盘下载器，也不会提前记为已安装。

### GitHub ZIP 为什么装不上？

源码 ZIP 不是 Decky 安装包，需先构建前端并准备运行依赖，再运行打包工具。

### 封面或百度 OAuth 不可用？

公开源码不含旧硬编码凭据。未设置 SteamGridDB Key 时跳过该层，其他封面来源仍可用。百度 OAuth 需要自己的应用配置，见 [开发文档](DEVELOPMENT.md)。

### 布局或手柄焦点异常？

确认只启用一个版本。反馈 Steam、SteamOS、Decky 版本、页面、桌面/游戏模式及截图。自动化预览不是实体设备完整兼容认证。

### 提交日志前需要做什么？

移除 Cookie、Token、账号、授权码、分享密码和私人路径。不要上传整个设置目录，只提交与问题有关的脱敏片段。
