# 使用指南

## 我的游戏

搜索游戏名，组合平台、收藏与排序条件浏览。卡片提供启动、Steam 详情和记录管理入口，设备未连接或文件已移动时显示不可用状态。

“移除记录”移除本插件库条目；“卸载文件”可能删除受管理的游戏文件，请阅读提示。游玩时间从本版本启用后观察并累计，不代表 Steam 历史总时长。

## 发现、PC 游戏与模拟器游戏

进入页面先显示本地目录，再后台更新。“刷新列表”重新读取最新本地结果；需要主动请求上游时进入“来源”，更新对应来源。

模拟器目录按平台显示。Switch 同时识别旧数据中的 `ns` 和 `switch`；有缓存时不需要等待远端恢复。

## 来源与获取

来源页显示条目数量、更新时间和异常状态。选择来源过滤浏览，在详情中查看获取方式并打开上游页面。

- Steam：在商店确认价格和兼容性后获取。
- Flathub：建议在 SteamOS 桌面模式通过安装页或 Discover 安装。
- 4TU：自制游戏项目页提供说明；NRO / hbmenu 与模拟器不是相同环境。

新增来源不自动下载或导入 Steam。安装后需要以适合该游戏的方式添加到 Steam。详见 [来源说明](catalog-sources.md)。

## 模拟器中心

选择平台，检查程序、配置与固件提示。可关联已有本地模拟器，再导入自己的 ROM。不同模拟器的程序与参数不同，请核对平台和可执行文件。

修改预设或恢复备份前阅读界面说明，备份只覆盖对应受管理文件。固件、BIOS 和游戏数据由用户自行合法取得。

## 稍后再玩、下载与登录

详情中的“稍后再玩”会保留条目及来源。原有网盘条目仍走原下载流程，商店条目打开外部页面。

队列区分下载、解压、导入阶段，下载完成不等于安装成功。失败时先查看具体阶段的错误。

本地游戏管理不要求云盘登录。公开源码中的百度应用凭据为空，未配置时 OAuth 不可用，详见开发文档。

## 手柄

页面使用 Steam / Decky 可聚焦控件。支持的标签区域可用 L1 / R1 切换，B 返回或关闭详情。不同 Steam 更新可能影响焦点，反馈时请提供页面和重现步骤。
